## 目前進度

- ✅ **計分板網頁**：全場點一下 +2、半場點一下 +1，上滑 +1、下滑 −1，撤銷、開新局，所有裝置即時同步
- ✅ **比賽紀錄**：開新局時選隊伍、點隊名改名；依日期的各隊戰績與每場比分，可編輯、刪除、復原，一鍵分享到 LINE
- ✅ **資料庫**：加分以事件記錄、撤銷不刪資料；自動進球支援籃框、換場對調、斷線重送不重複
- ✅ **進球判定邏輯**：軌跡 + 球框大小比例 + 籃網晃動，含單元測試與影片評估腳本
- ✅ **偵測 App 骨架**：選籃框、框選籃框、模擬進球、離線重送，GitHub Actions 自動編 APK
- ✅ **半場鬥牛**：全場／半場切換；App 偵測到的進球先待確認，計分板選隊伍才計分（App 端待實機驗證）
- ✅ **球員指認**（電腦離線）：本機網頁把影片裡的人分給球員或路人，可找相似、拖曳轉組、複查；靠衣著認，換一天要重新指認，見 [ml/](ml/README.md#指認球員精華剪輯用)
- ✅ **精華剪輯**（電腦離線）：鏡頭跟著球、字幕、慢動作，輸出 1080p；誰傳誰投要人工確認，自動判斷還不可靠，見 [ml/](ml/README.md#剪精華)
- ⏳ **實拍影片驗證**：10-30 半場 5 支（約 33 分鐘）離線評估，21 顆進球抓到 16 顆（召回率 76%）、判定 19 次有 3 次誤判（準確率 84%）；門檻是用同一批影片調的，數字偏樂觀。10-31 全場 6 支還沒標記
- ⏳ **App 的「眼睛」**：YOLO 和進球判定已接進 App，S23 上約 16 fps；目前只對著螢幕翻拍測過流程，還沒在球場用真的球驗證
- ✅ **手錶計分**（Galaxy Watch）：點螢幕或上下滑加減分、切換全場半場、下鍵開新局；沒有 Wi-Fi 時藍牙經手機上網，見 [watch/](watch/README.md)
- ⏳ **半場自動認隊伍（核心功能）**：打球時沒人會去選隊伍，要從進球往回追出手者、用衣著認人。目前只做到離線測試，進度見 [TODO](docs/TODO.md#核心功能半場自動認隊伍2026-11-04-列為核心)
- 💡 **之後想做**：罰球模式（自動算投幾進幾）、個人數據與能力評價（勝率、正負值、得分、命中率、籃板）、MVP，見 [TODO](docs/TODO.md)

## 功能目標

1. **多裝置共用計分板**：打開網址即進入同一場比賽，任一裝置加分即全部同步（房間代碼列為後期）
2. **自動辨識進球**：手機架在腳架上對準籃框，偵測球穿過籃框即自動加分
3. **雙籃框**：兩支手機各對一個籃框；換場對調在網頁操作，App 自動跟著換
4. **半場 3v3 鬥牛**：一支手機對唯一的籃框；鏡頭分不出哪一隊進球，先由場邊在計分板選隊伍
5. **分值**：自動進球全場記 2 分、半場記 1 分，網頁可改分（三分、罰球），並可撤銷；全自動三分列為後期目標

## 進球判定（摘要）

使用者在 App 畫面上**框選籃框一次**，YOLO 只在籃框周圍的偵測區找球，三道檢查都過才算進球：

1. **軌跡**：球先在框上方，1 秒內從框內往下穿出
2. **大小**：穿越時球徑約為框寬的一半，排除從框前或框後掉下的麵包球
3. **籃網晃動**：從球在框上方到穿越後 0.8 秒內，網子要晃
4. 判定後冷卻 2 秒

詳見 [docs/goal-detection.md](docs/goal-detection.md)。

## 開發

各目錄的 README 有完整說明。

```bash
# 計分板
cd web && npm install && npm run dev

# 進球判定測試
cd ml && pip install -r requirements.txt && pytest

# 偵測 App
cd app && flutter pub get && flutter run
```

GitHub Actions 依改動的目錄觸發：推送到 `main` 時部署 `web/`、編 `app/` 的 APK；`ml/` 的測試任何分支推送都會跑。
