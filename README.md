# 🏀 Scoreboard

籃球計分板：多裝置即時同步，YOLO 自動辨識進球。

## 目標

1. **多裝置共用計分板**：手機、平板用房間代碼加入同一場比賽，任一台加分即全部同步
2. **YOLO 自動辨識進球**：手機架在籃框前，偵測球穿過籃框就自動加分
3. **雙籃框**：兩支手機各對一個籃框、各對應一隊，換場時可對調
4. **分值**：預設自動記 2 分，一鍵改成 3 分或 1 分（罰球），並提供撤銷；全自動三分列為後期目標

## 技術選型

| 項目 | 選擇 |
| --- | --- |
| App | Flutter（Android 優先） |
| 即時同步 | Supabase Realtime |
| 進球辨識 | YOLO11n 或 YOLOv8n 轉 TFLite，裝置端推論 |
| 訓練資料 | Roboflow 籃球／籃框資料集 + 自行錄製影片 |

## 進球判定邏輯

追蹤球的**軌跡**，不看單張畫面：

1. 球先出現在籃框**上方**
2. 數幀內從籃框框內**往下穿出**，才判定進球
3. 判定後**冷卻約 2 秒**，避免重複計分
