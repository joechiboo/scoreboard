# web/ — 計分板（Vite）

網址：https://joechiboo.github.io/scoreboard/

## 操作

- **點一下**或**往上滑**比分：+1
- **往下滑**：−1（最低 0）
- **點隊名**：改這場的隊名，所有裝置一起更新
- **撤銷**：取消最後一筆加減分（含 App 自動記的分）
- **開新局**：選下一場的兩隊（快選 A～D 與今天出現過的隊名），目前這場存進紀錄，所有裝置一起切換
- **紀錄**：依日期看各隊戰績（勝敗、得失分）與每場比分、開局時間、打了幾分鐘，可「分享到 LINE」或複製文字
  - 時間取自開新局的時間點：這場開始＝按開新局時，結束＝下一次按開新局時
  - **點一場**可改隊名、比分或刪除：改比分是補一筆手動加減分，原本的紀錄不動；刪除是把該場加分全標成撤銷（比分 0:0 就不顯示），紀錄頁會出現「復原」可救回
  - 凌晨 5 點前開的局算前一天，打到半夜不會被拆成兩天
  - 0:0 的局不列入；進行中的那場只列比分，按「開新局」結束後才算進戰績
- 左下角燈號：綠色已連線、紅色未連線；「?」按鈕顯示操作說明

## 開發

```bash
npm install
cp .env.example .env   # 填入 Supabase URL 與 publishable key
npm run dev
```

| 檔案 | 內容 |
| --- | --- |
| `src/api.js` | Supabase 資料存取：目前比賽、比分、加分、撤銷、開新局、Realtime 訂閱 |
| `src/main.js` | 畫面與手勢；樂觀更新、亂序回應保護；開新局、改隊名、紀錄對話框 |
| `src/records.js` | 紀錄統計（純函式）：依日期分組、各隊戰績、LINE 分享文字 |
| `src/style.css` | 版面：橫向左右並排、直立上下排列 |

推送 `web/` 的改動到 `main` 後，GitHub Actions 會自動部署到 GitHub Pages（`.github/workflows/deploy-web.yml`）。
