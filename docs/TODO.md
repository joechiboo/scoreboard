### 半場鬥牛模式

一支手機對唯一的籃框就好，器材比全場簡單，也沒有三分；唯一難的是**兩隊投同一個籃框，鏡頭只知道「有進球」，不知道是哪一隊**。

- [x] 網頁「全場／半場」按鈕：預設全場，按一下切換，所有裝置同步，開新局沿用；半場點一下 +1
- [x] 套用資料庫變更 `supabase/migrations/20261022000000_game_mode.sql`（2026-10-22 在 Supabase SQL Editor 執行）
- [ ] App 依模式記分：半場自動進球記 1 分、先不帶隊伍
- [ ] 先做半自動：App 偵測到進球後，計分板跳出「誰進的？」讓場邊點一下隊伍（點錯可撤銷）；資料庫要讓半場的自動進球先不帶隊伍，等確認再記上
- [ ] 沒人點也不擋比賽：先記成「待確認」，之後在計分板或紀錄裡補點
- [ ] 之後再全自動：從進球往回找出手的人，判斷他是哪一隊
  - 有穿背心 → 我方；清楚看到、確定沒穿 → 對方
  - 找不到出手的人、被擋住或看不清楚 → **待確認**，跳出來讓人點，不要直接算給對方（不然對方會一直被多記分）
- [ ] **買背心：只有我方穿，三件**（2026-10-22 決定）。辨識只要分「有沒有穿背心」，比分兩種顏色簡單
  - 蝦皮關鍵字：「號碼背心 螢光」「分隊背心 號碼」「訓練背心 網眼 號碼」；成人 L～XL，套在衣服外面要夠大
  - 多買一件備用（四件）也可以，有人換手時用
  - 螢光黃或螢光綠，避開黑白灰藍等常見衣服顏色，也避開球場地板的綠、紅
  - **要有號碼**（2026-10-22 決定）：我方三人同色背心，個人得分要靠號碼分辨誰是誰
  - 號碼要大：背後最好 20 公分高，前後都印更好；黑字配螢光底，避開白字、細框字
  - 一位數、形狀差很多，例如 1、4、8；不要同時用 6 和 9（轉身、歪斜時會看反）
  - 號碼不是隨時讀得到（背對、側身、離太遠）：讀得到時確認身分，其餘靠追蹤接起來；對方沒背心仍靠衣服認人
  - 早點買：跟同事打半場時穿著錄影，影片就能直接拿來測背心辨識
- [ ] 不建議用「進球後換誰發球」去猜：各地鬥牛規則不同（輸球發球／贏球繼續），猜錯就記錯隊
