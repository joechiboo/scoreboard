## 場地配置（半場 3v3）

三台裝置各有各的位置，彼此不要擋：

```
                 圍網
   ┌───────────────────────────────────┐
   │   [平板]                         │  ← 平板夾在底線／邊線圍網，胸口高
   │    ╭──────── 籃框 ────────╮        │
   │    │        ( )          │        │
   │    │     三分線弧        │  [偵測手機]  ← 場外，距籃框 6～7 公尺
   │    │                     │        │
   │    ╰─────────────────────╯        │
   │                                   │
   │                  [4K 錄影]        │  ← 更遠，拍整個半場
   └───────────────────────────────────┘
```

### 偵測手機（App）

- 腳架放**場外**，離籃框約 6～7 公尺，移近到 App 不跳「籃框太小」為止；三分線內的人盡量都入鏡
- **手機上緣朝左**橫放（鏡頭畫面只鎖這個方向，架反了畫面會倒）
- 籃框要完整入鏡、不被籃板和籃架擋住；從高處斜拍，籃框在畫面上呈橢圓
- 燈不要正對鏡頭，也不要讓籃框逆光
- 行動電源接著，線沿腳架綁好，不要橫過走道
- 腳架架好**才**框籃框；中途被撞到要重新框選

### 4K 錄影裝置

- 放更遠，拍到整個半場、整條三分線和所有人
- 設定照[錄影指南的手機設定](recording-guide.md#手機設定出發前調好)：UHD 60fps、一般錄影模式、關防手震與 HDR、鎖對焦、飛航模式
- 錄到一半偶爾看一眼有沒有過熱停錄

### 計分板平板

**不要放地上**：站著看不到數字、會被踩到或被球打到、地面反光。

兩個可行的位置，看現場哪個方便：

| | 夾在圍網上 | 吊在球架柱子上 |
| --- | --- | --- |
| 怎麼固定 | 平板夾（圍網夾或 1/4 吋螺孔＋小雲台） | 綁帶式平板架（單車把手那種魔鬼氈綁帶，柱子粗約 10～15 公分要綁得住），或掛鉤＋平板保護套的吊繩 |
| 高度 | 胸口到眼睛 | 比頭高一點（約 2 公尺），伸手搆得到就好 |
| 好處 | 離球遠、不會被撞；要補選隊伍走兩步就到 | 大家本來就看著籃框，比數就在視線裡；不用找圍網 |
| 壞處 | 得在籃框斜後方或邊線中段才看得順 | 籃下人擠、搶籃板會撞柱子，球打籃板的震動也會傳到柱子；補選隊伍要走到籃下 |
| 注意 | 位置離場內一兩公尺 | 要有柱墊或綁在柱墊上方；平板套防摔殼；不要放在偵測手機的籃框偵測區內（柱子在籃框下方，正常不會） |

- 兩種都不行就放場邊長椅或自帶折凳，用支架立起來（高度只到膝蓋，可讀性差一截）
- 不要跟偵測手機共用腳架，也不要放在偵測手機旁邊（6～7 公尺外看不清楚）
- 行動電源掛在圍網上或放腳邊，線沿圍網走
- 計分板本來就多裝置同步：平板放得穩就好，誰要確認比數或補選隊伍，空檔用自己手機開同一個網址也行
- 螢幕亮度調最高；防黑屏（Wake Lock）已上線，這次順便實測

## 開打前

1. 平板開計分板，切成**半場**，開新局、清掉測試留下的比分
2. 偵測手機開 App → 開始偵測 → 照著鐵圈框住籃框 → 看到「找球 fps」
3. 4K 錄影裝置按錄影前看畫面 30 秒：籃框完整沒被擋、三分線整條在畫面裡、橫向沒變焦
4. 跟一起打球的人說一聲有錄影，影片只放自己的電腦
5. **認人**：三位球員輪流在鏡頭前走動約 10 秒，當天不換衣服
6. 偵測手機和 4K 都接上行動電源再開打

## 打球中

- 自動進球在半場會先記成「待確認」，提示條不擋計分；空檔有人經過平板再點隊伍，點錯可撤銷
- 偶爾看一眼：App 有沒有還在跑（fps 還在跳）、4K 有沒有過熱停錄、腳架有沒有被撞
- 腳架被撞到：App 要重新框選

## 打完

1. 平板：這場的待確認進球補點完再開新局（開新局後目前看不到、也補不了）
2. 4K 影片用隨身碟**移動**（不是複製）到電腦，放 `ml/datasets/videos/<日期>_<場次>/`，隨身碟不留檔
3. 拉偵測手機的每幀記錄：

   ```bash
   adb pull /sdcard/Android/data/com.joechiboo.scoreboard_detector/files/trace ml/datasets/trace
   ```

4. 對答案：用 4K 影片標這場的進球 CSV（格式見[錄影指南](recording-guide.md#標記格式)），跟 App 判定的比，調門檻（手機目前 0.025）
5. 做賽後算分工具：串進球判定、追出手者、認人；進度在 [TODO](TODO.md)
