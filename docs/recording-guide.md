# 錄影指南

實拍影片是驗證進球辨識最關鍵的素材，錄了就能一直重複使用。

## 連假錄影計畫（2026-10）

| 段 | 內容 | 長度 | 檔名 |
| --- | --- | --- | --- |
| 1 | 全場，1 號籃框（腳架在這一邊） | 1 小時 | `full-hoop1.mp4` |
| 2 | 全場，2 號籃框（腳架換到另一邊） | 1 小時 | `full-hoop2.mp4` |
| 3 | 半場鬥牛，角度 A：籃下底線後方往場內 | 30 分鐘 | `half-angleA.mp4` |
| 4 | 半場鬥牛，角度 B：場外邊線往場內 | 30 分鐘 | `half-angleB.mp4` |

- 半場那兩段請**我方穿背心**，之後才能測背心辨識
- 一段錄成一個長檔沒關係，我會自己切
- **容量**：4K 一小時大約 20 GB 以上，三小時要 60 GB 起跳。每錄完一段就先傳到電腦、清出手機空間
- **傳檔**：用傳輸線把影片複製到這台電腦的 `D:\Personal\Project\scoreboard-videos\`（不進 Git），比上傳 Google Drive 快，也不會卡在 Drive 免費 15 GB 的上限
- **標記**：每段先標前 15 分鐘就夠開始評估；也可以先讓我用現成模型掃一遍，列出「可能進球」的時間，你只要逐一確認或刪掉

## 為什麼錄廣角

**錄一次、兩種用途**：廣角影片可以裁切籃框附近，驗證進球判定；整個畫面留給之後的三分判定。只拍籃框的近拍，以後沒辦法拿來做三分。

真正花時間的是收集和標記影片，模型重新訓練只要幾個小時，所以盡量一次錄到位。

## 器材與擺放

| 項目 | 建議 |
| --- | --- |
| 腳架 | 一定要用，拉到最高（1.8 公尺以上），錄影中不能移動 |
| 位置 | 底線和邊線交角附近的斜後方，或中場線後方中間；要拍得到**籃框和整條三分線** |
| 角度 | 從高處往下拍，籃框在畫面上呈橢圓；避免和籃框同高正對（前後的球會疊在框上） |
| 方向 | 橫向拍，鏡頭固定，不要變焦 |

有兩支手機的話：一支廣角、一支近拍籃框，同時錄同一段，直接比較兩種拍法的準確率。

## 兩種角度試錄比較

還不確定哪個角度好，先各錄 30 分鐘比較（同一個籃框、同一天、光線接近）：

| | A：籃下，底線後方往場內拍 | B：場外，邊線往場內拍 |
| --- | --- | --- |
| 擺法 | 底線後 2～3 公尺的場外，架到 1.8 公尺以上；**往左或右偏一點**，避開籃板和籃架擋住籃框 | 邊線外，大約罰球線的延長線上，架高；畫面要有籃框和整條三分線 |
| 進球判定 | 籃板不透明時會擋住籃框；正對籃框時球在框前、框後分不出來，所以要偏一邊、從高處拍 | 籃框呈橢圓，球從框上穿到框下最清楚，預期最準 |
| 誰出手、背心 | 球員面向鏡頭，背心正面和出手動作都看得清楚，**半場判斷哪隊進球最有利** | 從側面拍，球員前後互相擋住 |
| 三分 | 整條三分線弧在鏡頭前方，出手點在線內或線外好判斷 | 看得到，但離鏡頭遠的那一側會變小 |
| 籃板 | 籃下人擠人，從後面拍容易被擋 | 側面看得到誰跳起來拿到球 |
| 要注意 | 救球衝出底線可能撞到腳架，要拉遠或放角落 | 邊線有人走動會擋到鏡頭 |

- 檔名分開：`angleA_01.mp4`、`angleB_01.mp4`，各配一份同名 CSV
- 錄完我會分別算：進球抓到幾成、誤判幾次、出手的人看得清楚的比例
- 結果可能是兩種各有用途：例如 B 用來自動計分，A 用來判斷半場哪隊進球；手機只有一支時再挑一個

## 錄影規格

- **解析度**：4K 優先（廣角時籃框和球很小，裁切後才有足夠細節）
- **幀率**：能開 60fps 就開（球比較不糊）；4K 和 60fps 只能二選一時，兩種各錄幾段比較
- **長度**：每段 5～15 分鐘即可，方便標記與傳輸

### 手機設定（出發前調好）

| 設定 | 調成 | 原因 |
| --- | --- | --- |
| 解析度／幀率 | 4K 60fps；只能 4K 30fps 就用 4K 30fps | 解析度比幀率重要 |
| 鏡頭 | 1 倍主鏡頭；拍不到整個半場才用 0.5 倍廣角 | 廣角鏡頭畫質較差、邊緣變形 |
| 防手震 | 關（含超級防手震、運動模式） | 腳架已固定；防手震會裁畫面、畫面會飄 |
| HDR 影片 | 關 | 處理麻煩、顏色容易跑掉 |
| 編碼 | H.265／HEVC（「高效率」） | 檔案小一半 |
| 對焦、曝光 | 長按畫面上的籃框鎖定 | 人跑過時不會忽明忽暗、重新對焦 |
| 通知 | 飛航模式或勿擾 | 來電可能中斷錄影 |

每一小時至少留 25 GB 空間，接行動電源。

## 要錄的內容

每種都要有，越多越好：

- [ ] 一般進球（中距離、上籃）
- [ ] 三分進球
- [ ] 罰球
- [ ] 空心進球、擦板進球
- [ ] 打框彈出
- [ ] 在框上滾一圈才進／才掉出
- [ ] 麵包球：投短（從框前掉下）
- [ ] 麵包球：投遠（從框後掉下）
- [ ] 有人擋住鏡頭、有人在籃下搶籃板
- [ ] 不同光線：白天、晚上、逆光

## 標記格式

每段影片一個同名 CSV（`clip01.mp4` → `clip01.csv`），每行一顆球：

```csv
時間,結果,分數
0:12.5,進,2
0:20,沒進,
1:02.5,進,3
1:30,麵包球,
```

- **時間**：球穿過（或經過）籃框的時間，秒數（`72.5`）或分:秒（`1:12.5`）皆可，誤差 1 秒內即可
- **結果**：`進` 才算進球；其他寫法（`沒進`、`麵包球`、`打框`）都當沒進，可自由註記
- **分數**：進球記 2／3／1，之後訓練三分判定會用到；半場一律記 1
- **隊伍**（半場才需要，第 4 欄）：`我` 或 `對`，用來驗證背心辨識能不能判斷哪一隊進球

```csv
時間,結果,分數,隊伍
0:31,進,1,我
1:05,沒進,,
1:48,進,1,對
```
- `#` 開頭的行是註解

偷懶做法：錄影時口頭喊「進」「三分」，之後邊看影片邊記。
